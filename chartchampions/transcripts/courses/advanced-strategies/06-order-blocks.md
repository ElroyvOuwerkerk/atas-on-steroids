# Order Blocks

## Portal Summary & Highlights

We also have cheat sheets available for this topic which can be downloaded as a high-res PDF via our vault section here : https://portal.chartchampions.com/vault - download is titled ‘Order Blocks’

This livestream focuses on teaching traders how to effectively trade order blocks in the cryptocurrency markets. The presenter, inspired by ICT's order block technique, aims to provide a comprehensive guide on identifying, analyzing, and trading both bullish and bearish order blocks. The session covers the background, theory, and practical application of order blocks, emphasizing the importance of confluences with key levels, swing highs/lows, and advanced order flow analysis using clusters.
