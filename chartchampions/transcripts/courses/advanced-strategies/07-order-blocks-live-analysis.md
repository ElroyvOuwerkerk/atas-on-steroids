# Order Blocks: Live Analysis

## Portal Summary & Highlights

This educational trading stream focuses on identifying and trading high-probability order blocks using order flow tools like ExoCharts and ATAS. Viewers learn how to merge multiple order blocks using the Fixed TPO Range tool, identify key volume confluences, use the 78.6% Fibonacci retracement for low-risk entries, and develop a complete trading plan with patience-based execution on lower timeframes.

### Detailed Timestamps:

- [00:00] Introduction to putting theory into practice Ñ focus on identifying high-probability order blocks and using ExoCharts/ATAS to zoom into clusters and form a trading plan.
- [00:34] Order block definition clarification: An order block is the last candle OR a series of candles in the opposite direction before an impulsive move. Two 30-minute bearish candles = a 1-hour order block.
- [01:21] Order blocks form at or near key levels of resistance/support. Introduction to using the Fixed TPO Range tool to merge multiple order blocks for multi-timeframe order flow analysis on lower timeframes.
- [02:29] Discussion of imbalances, set ratios, and mitigation Ñ how traders close trapped positions when price returns to the order block.
- [03:00] Introduction to Footprint Bar Statistics for quick visual identification of standout candles based on color/volume.
- [03:46] Practical demonstration on daily chart: using fractals to identify swing highs/lows, then drawing order blocks with the 0.5 to 0.25 Fib range.
- [04:47] Reading market structure: identifying a swing failure pattern and anticipating an order block hold without a confirmed structure change. Trading below the 0.5/0.25 = bearish bias.
- [05:38] Key principle: Use bearish order blocks for shorts in downtrends, bullish order blocks for longs in uptrends Ñ trade with the dominant trend.
- [06:07] Switching to ExoCharts Desktop Ñ loading clusters template, setting 21-day lookback, examining point of control (POC), value area high/low.
- [07:34] Analyzing candle internals Ñ looking for strong delta and volume to validate a bullish block. A weak candle with insufficient volume reduces probability of holding.
- [09:05] Setting alerts at the POC level and waiting for price to arrive Ñ then loading the 1-minute/5-minute CCTR template to track market structure.
- [10:00] Execution rules: Wait for fractals to break to the upside before entering. Don't chase the breakout Ñ wait for the reaction and pullback to your level.
- [10:25] Switching to 4-hour timeframe analysis Ñ identifying the lowest bullish order block and recognizing when small bodies are inferior to larger 4H blocks.
- [11:27] Merging order blocks in ATAS using the Fixed TPO Range tool (F3 shortcut) to combine multiple candles into a single zone of confluence.
- [12:31] Heatmap configuration in ATAS: Setting cluster mode to "Volume Proportion" for heat map visualization and "Bid/Ask Centered" content for clear order flow visibility.
- [14:53] Demonstrating the merge: Combining two 4-hour candles to find combined Value Area High and POC at 18,800 area. Using F4 for the value tool to mark levels.
- [16:40] Mitigation theory explained in depth: Large traders holding short positions need price to return to close out. Upon market structure breaks, they buy back AND go long Ñ fueling impulsive second-leg moves of 5-10%.
- [20:08] The 78.6% Fibonacci confluence trick: Drawing fib from low to high reveals the 0.786 level aligns with the order block Ñ providing a low-risk entry with target at the prior high (21,920).
- [21:27] CVD analysis context: CVD on higher timeframes is less crucial because old traders are already stopped out. Focus on lower timeframe CVD for fresh money signals when price reaches your level.
- [22:31] Comparing the same setup in ExoCharts Desktop Ñ using volume profile and delta cluster to confirm the same confluence zones (data discrepancies between platforms are normal).
- [24:13] The complete strategy summary:
  - Find order blocks at key higher timeframe levels (first confluence)
  - Look for second-layer confluence (Fib levels, POCs)
  - Zoom into clusters to identify volume details
  - Set alerts and be patient
  - When alert triggers, drop to 1-5 minute charts
  - Wait for fractal market structure break
  - Buy the pullback, not the breakout
  - Track, log, rinse, repeat

Key Takeaway: Patience is the missing ingredient Ñ once you've identified your high-probability zone, the work is done. Set the alert, wait for price to arrive, and let lower timeframe market structure dictate execution. Apply this systematic approach to dramatically improve your trade selection and risk-to-reward profile.
